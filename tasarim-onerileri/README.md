# Tasarım Önerileri — Geldi Geçti Hatıralar

Bunlar web sitesi **yapılmadan önce** onay için hazırlanmış tasarım taslaklarıdır.
Görseller temsilidir; gerçek sitede Instagram hesabındaki (@geldigecti_hatiralar)
Reels, fotoğraf ve açıklamalar kullanılacaktır.

| Öneri | Dosya | Önizleme |
|---|---|---|
| **D — Instagram Profili Gibi** | `d-instagram-profili.html` (gönderi detayı için sonuna `#detay` ekleyin) | `onizleme/D1-…`, `D2-…`, `D3-…` |
| **E — Renkli Hatıra Akışı** | `e-renkli-akis.html` | `onizleme/E-…` |

HTML dosyalarını bilgisayarınızda çift tıklayarak tarayıcıda açabilirsiniz.
